## XiReader 1.2.0-beta.7

- 在同一篇文献内继续 Codex 阅读会话。可以从批注发起问题，核对要发送的页码和选文，并在预览后把回答追加到笔记或批注。使用阅读会话需要本机已登录的 Codex CLI。
- 左右侧栏可调宽或折叠。Obsidian 文献栏按知识库文件夹浏览，目录条目支持单独校正目标页码。
- 原位 PDF 被替换时，其他文献仍可阅读。确认源文件后可重新关联，保留原有笔记和批注。
- macOS 应用显示为 XiReader，沿用已有文献库与插件配置。Windows 入口为 `Paperdesk.exe`。浏览器版需要 Node.js 24 或更高版本。

升级前请保存并退出旧版，备份文献库及会话。按平台下载完整包，并使用同页 SHA-256 清单核对文件。
